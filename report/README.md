# DisasterLens Technical Report Sections

This directory contains the dataset, methods, results, and reproducibility sections
prepared for incorporation into the final DisasterLens report:

1. [Dataset / Inputs](01_dataset_inputs.md)
2. [Methods: Vision Module](02_methods_vision.md)
3. [Methods: NLP Module](03_methods_nlp.md)
4. [Results: Vision](04_results_vision.md)
5. [Results: NLP](05_results_nlp.md)

All reported counts and model metrics come from the generated CSV or JSON artifacts
in `disasterlens_modules/data/` and `disasterlens_modules/models/`. The conflict
fixture is a controlled evaluation set and is not used to estimate the prevalence
of multimodal disagreement in operational disaster reports.
